# Titanic Data Cleaning and Preprocessing

## Project Overview
This project focuses on cleaning and preprocessing the Titanic dataset to prepare it for machine learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Tasks Performed

1. **Data Exploration**
   - Loaded the Titanic dataset.
   - Checked dataset shape, data types, and missing values.

2. **Handling Missing Values**
   - Filled missing Age values using the median.
   - Filled missing Embarked values using the mode.
   - Removed the Cabin column due to a large number of missing values.

3. **Encoding Categorical Variables**
   - Applied label encoding to the Sex column.
   - Applied one-hot encoding to the Embarked column.

4. **Feature Scaling**
   - Applied Min-Max Scaling and Standardization to numerical features.

5. **Outlier Detection**
   - Used boxplots to visualize outliers.
   - Applied the IQR method to identify potential outliers.

## Dataset
Titanic Dataset – Kaggle.

## Learning Outcomes
- Understanding data exploration and cleaning.
- Handling missing values.
- Encoding categorical variables.
- Applying feature scaling.
- Detecting outliers using statistical methods.

## Conclusion
This project provided practical experience in data cleaning and preprocessing using Python libraries.
